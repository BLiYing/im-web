# Web UI 配色与外观规范

> **三端共同规则以 `../../IMServer/docs/UI_COLOR.md` 为准**（语义令牌总表、文本层级、
> 页面/卡片/输入口径、聊天个性化、深色验收清单、新功能检查清单）。本文只写 im-web
> 的入口与 **Web 平台特有**的约束。
>
> CSS 变量是颜色、间距和圆角的唯一入口；用户外观偏好由 React 状态统一写入
> `document.documentElement.dataset.theme`，业务组件不得自行维护另一套主题。
> 审计记录见 [UI_COLOR_AUDIT.md](UI_COLOR_AUDIT.md)。

## 1. 变量声明纪律

- CSS 自定义属性必须在 `:root` 声明，**不得依赖 `var(--name, 临时颜色)` 长期兜底**——
  fallback 会把"忘了声明"伪装成正常。
- 颜色的透明变体也要成为令牌，禁止在组件里重复写 `rgba(...)`。
- 迁移期别名：`--bg`、`--line`、`--badge` 可继续作为 `--grouped-bg`、`--separator`、
  `--unread-badge` 的兼容别名；**新代码不得再引用这些旧名字**。
- 令牌与 iOS 的对应关系见跨端主文档 §2 的总表（改那张表 = 改两端）。

## 2. 标题栏与导航（Web 落地方式）

- 返回、保存、普通操作使用 `--accent`；危险操作使用 `--danger`。
- 标题栏使用 `--page-bg`，分割线只能使用 `--separator`。
- 媒体上的白色按钮必须有 `--overlay` 或阴影承托，确保明暗图片上都可见。

## 3. 层级：卡片 / Modal / 浮层菜单

三层的用色**不可互相借用**，这是 Web 侧最容易糊掉的一处：

- **页面卡片**：`--card-bg`（在 `--grouped-bg` 的页面上）。
- **Modal**（`.modal` 层：模态对话框、确认框、选择器）：`--surface-elevated`，圆角统一
  `--radius-card`，不与页面卡片共用同一层级色。
- **浮层菜单 / Popover**（附件加号菜单、右键/长按消息菜单、会话/成员/文件·媒体菜单、账号菜单、
  资料卡「更多」、查看器「更多」、@提及面板……一切浮层菜单同一套观感）：
  `--glass-menu-bg` + `--glass-menu-border` + `backdrop-filter` 毛玻璃，深浅色分别提供玻璃底色。
  文字、图标、边框、Hover 仍必须用语义令牌。
  **必须写 `@supports not (backdrop-filter…)` 兜底**：不支持时退回不透明 `--surface-elevated`
  + `--separator`，否则半透明无模糊会让背后内容透出、文字不可读。
  玻璃令牌**只用于这些浮层菜单**，不得下放到页面卡片或 Modal。

## 4. 壁纸与桌面布局（Web 特有）

- 聊天壁纸由**应用根节点唯一的背景层**渲染，位于会话、聊天和资料卡片之下；禁止页面自行复制壁纸层。
- 背景模糊只允许作用于根壁纸层，**不得模糊**消息、输入栏、设置页或资料卡片。
- 桌面布局用同一个 `--app-gap` 作为屏幕外边距、左右栏间距和聊天/资料间距。
- 左会话卡片与右资料卡片使用相同宽度和高度；聊天标题必须包含会话头像、主标题和
  状态/群成员数副标题。
- 所有圆形头像使用 `--avatar-ring` 外框，确保照片或回退色与卡片背景之间有清晰边界。
- 文本必须允许自然换行或省略，字号变化后禁止依赖固定高度。
- **Web 不支持切换系统应用图标**（iOS 的 Alternate Icons 无对应能力）；PWA 图标只能由
  manifest / 打包资源决定。

## 5. 深色模式的 Web 具体取值

跨端验收清单见主文档 §6，以下是 Web 独有的取值口径：

- 普通页面主底色 `#242424`，分组背景更暗的 `#1f1f1f`，卡片和浮层依次提高明度；
  **禁止将纯黑作为大面积页面、侧栏或卡片背景**——纯黑只留给遮罩、阴影和媒体渐变。
- 会话选中态必须明显区别于普通 Hover：浅色模式用 24% 主色混合底，深色模式用 32% 亮绿混合底；
  不得靠降低透明度把选中态弱化成接近普通列表背景。
- 分别检查 `light`、`dark`、`system + prefers-color-scheme: dark` 三种。

## 6. 本端额外检查项

在跨端检查清单（主文档 §7）之外，Web 提交前还要过：

1. 变量是否已在 `:root` 声明——**禁止用 fallback 掩盖遗漏**。
2. 桌面双栏与窄屏单栏各检查一次。
3. 新增浮层菜单是否带 `@supports` 兜底、是否误用玻璃令牌到卡片/Modal 上。
